# Summarization

## 1. Extractive Summarization
**Extractive Summarization** works like a highlighter pen. It reads a long document, evaluates every single sentence, and "extracts" the top $N$ most important sentences exactly as they were written. It does not generate any new text.

### Sentence Scoring
To determine which sentences are "important", the algorithm assigns a score to each sentence based on the words it contains. The most common classical method uses **TF-IDF** (Module 12).
1. Calculate the TF-IDF score for every word in the document.
2. For each sentence, sum the TF-IDF scores of all the words in that sentence.
3. Divide by the length of the sentence (to prevent the algorithm from just picking the longest sentences).
4. Rank the sentences by their normalized score and output the top 3.

## 2. Abstractive Summarization
**Abstractive Summarization** works like a human. It reads the document, understands the meaning, and generates an entirely new, shorter text that captures the core concepts, often using words that did not appear anywhere in the original document.

Abstractive summarization relies on Neural Seq2Seq models (like BART or T5). It is much harder than extractive summarization because the model must maintain grammatical fluency and avoid "hallucinating" facts that weren't in the source text.

## 3. Scratch Implementation (Extractive Sentence Scoring)
```python
def score_sentences(text: str, word_scores: dict[str, float]) -> list[str]:
    # Very simple sentence tokenizer (splitting by period)
    sentences = [s.strip() for s in text.split('.') if len(s.strip()) > 5]
    
    sentence_scores = []
    
    for sentence in sentences:
        words = sentence.lower().split()
        score = sum(word_scores.get(word, 0.0) for word in words)
        
        # Normalize by length to prevent bias toward long sentences
        normalized_score = score / len(words) 
        
        sentence_scores.append((sentence, normalized_score))
        
    # Sort by score descending
    sentence_scores.sort(key=lambda x: x[1], reverse=True)
    
    # Return just the text of the top 2 sentences
    return [s[0] for s in sentence_scores[:2]]

# --- Trace ---
text = "The quick brown fox jumps over the lazy dog. The sun is shining. The fox is very quick and brown. It is a nice day."

# Assume these scores were generated by TF-IDF on a large corpus
tf_idf_scores = {
    "fox": 5.0,
    "quick": 4.0,
    "brown": 3.0,
    "sun": 1.0,
    "dog": 2.0
}

summary = score_sentences(text, tf_idf_scores)
print("Summary:")
for s in summary:
    print(f"- {s}.")

# Output:
# Summary:
# - The fox is very quick and brown.
# - The quick brown fox jumps over the lazy dog.
```

### Likely Theory Question
**Question**: Explain why normalizing the sentence score by the sentence length is critical for Extractive Summarization.
**Answer**: If a summarization algorithm simply sums the TF-IDF scores of the words in a sentence, it will naturally favor extremely long sentences because they contain more words and therefore accumulate more total score. Normalizing the score by dividing by the word count calculates the average "density" of importance per word, allowing short, highly-informative sentences to outrank long, rambling sentences.
