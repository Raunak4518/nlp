# 30. Evaluation & Metrics

## 1. What this topic is
This module is a capstone review of every major evaluation metric used in Natural Language Processing, explaining which metric is appropriate for which task.

## 2. Why it matters in NLP
Using the wrong metric will cause you to deploy a fundamentally broken model to production. You must know when to use Accuracy, when to use F1, when to use BLEU, and when to use Perplexity.

## 3. What the student will learn
- A review of Perplexity and F1.
- Why Token-Level Accuracy fails for NER.
- How Entity-Level F1 works.
- The conceptual difference between BLEU (Precision-focused) and ROUGE (Recall-focused).
